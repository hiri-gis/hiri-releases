# Hiri

A free desktop app for earth-observation analysis: land cover, vegetation, water, fire,
growing-season timing and terrain, computed from satellite imagery it fetches itself.
Pick an area on a map, fill a short form, press Run.

## Download

Get the latest installer from [Releases](https://github.com/terra-gis/hiri-releases/releases/latest).

- **Windows 10/11, x64.** Installs per user; no administrator rights needed. The installer is
  not code-signed, so Windows shows "Windows protected your PC" the first time — choose
  **More info → Run anyway**.
- **macOS** is not released yet.

Installed copies check this page for updates at launch and only install one when you ask.
